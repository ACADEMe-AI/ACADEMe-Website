# Overview

This site is the design system for ACADEMe.

## Who it is for

* Founders checking the next step  
* Agents that need rules without searching the whole repo  
* Anyone shipping brand, product, or app UI  

## How to use it

1. Open **What next** for the current checklist  
2. Open **Brand** when you need logo or color  
3. Open **Character** for the learning buddy assets  
4. Open **Build** before writing code  

## Two sites

| Site | Job |
|------|-----|
| Marketing site | Sell the app and drive installs |
| This design system | Rules and assets for builders |

Keep them separate. Do not mix launch copy into engineering rules.
