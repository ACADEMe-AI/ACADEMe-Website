# In the app

Moments where the learning buddy appears.

## Show

* First open and onboarding  
* Empty library (upload invite)  
* AI is thinking  
* Practice test finished  
* Streak milestone  

## Hide

* Every course card  
* Dense settings forms  
* When the user turns the character off  

## Copy

Keep short. Prefer “Nice work” or “Almost there” over long praise.
