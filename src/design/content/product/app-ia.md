# App structure

## Tabs

A floating nav pill with four tabs, and a separate round Scan key next to it.

| Tab | What's there |
|-----|--------------|
| **Home** | Greeting, class and board, streak and XP, ask field, quick actions (Solve homework · Check my answer · Flashcards), Today card, subjects |
| **ASKMe** | Chat with Pebby: Explain · Solve · Quiz me. The pill turns into the ask bar here |
| **Study** | Courses (chapters and lessons) and Folders (tests, plans, notes) |
| **Me** | Class and board, app language, Appearance, reminders and daily goal, help, account, Pro |
| **Scan** (key) | Solve · Check my answer · Notes · Ask |

## Main flows

```
Sign up → setup (language, birth year, class, board) → Home
Home → Study → Courses → chapter → lesson cards → quick check → lesson done → revision
Any card or scan → Ask Pebby → ASKMe
Scan key → pick a job → camera or gallery → fix the text → answer or marks
Study → Folders → new folder → chapters + test date → plan → Today on Home → reminders
```

## Rules

- Scan and ASKMe are one tap from anywhere
- Every lesson card and every scan result has "Ask Pebby"
- No paywall in setup. The limit sheet appears only when a daily limit is reached
- Coming-soon chapters are listed but greyed out, never hidden
